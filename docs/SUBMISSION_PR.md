## Product description

Students discover real official-source scholarships, save versioned profiles, inspect three-outcome eligibility with evidence, and manage private application plans. Reviewed source changes preserve history, recalculate affected profiles and produce durable, preference-aware alerts. Source fetching runs separately from matching/delivery. Retrieval failure preserves accepted facts and successful timestamps.
