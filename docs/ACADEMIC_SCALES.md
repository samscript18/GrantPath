## Product behavior

- Searchable country choices use canonical names and keep citizenship separate from residence. Institutions allow custom entries because the scholarship catalogue is not a global university directory.
- Classification suggestions are selectable original labels, with custom wording preserved. They are not a claimed cross-country mapping.
- Original numeric result stays editable, original scale offers suggestions/custom numeric entry, and grading direction is recorded. No converted GPA replaces those values.
- Engine **1.2.0** uses only provider-authored equivalences already attached to scholarship rules. Unsupported scales return GPA_SCALE_UNSUPPORTED. An inverted original scale returns GPA_DIRECTION_UNSUPPORTED rather than passing or failing a normal minimum-GPA comparison.
- The reference collection itself does not publish or silently alter a scholarship rule. A new equivalence still requires the provider's applicable evidence and normal operator review/versioning.

No claim is made that all available conversions worldwide have been researched. Institutions and scholarship providers retain the final assessment.
